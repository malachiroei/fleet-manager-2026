## למה רביד רואה גם רכבים של מנהל-העל אחרי ה-SQL הלא נכון

- ב-RLS, משתמש עם הרשאות **fleet staff** רואה **את כל הרכבים/נהגים ב-`org_id` שלו**.  
- עדכון מסוג `UPDATE vehicles SET org_id = '…' **בלי WHERE**` שם **את כל הרכבים** באותו ארגון — ואז כל אדמין באותו org רואה את הכל.  
- זו לא באג בקוד האחרון; זו **מציאות נתונים** אחרי מיזוג גורף.

### איך להפריד שוב (בחירה מוצרית)

- **אופציה א' (מומלץ לריבוי לקוחות):** ארגון נפרד לצי של מנהל-העל / דמו, והעברת שורות רלוונטיות + `org_members` בלבד לשם (עם `WHERE` ספציפי).  
- **אופציה ב':** להשאיר org אחד ולסמן בעלות עם `managed_by_user_id` על רכבים/נהגים — דורש משמעת בהזנה עתידית (ואולי כלים במוצר).

## מה לא לעשות לעולם

- **לא** `UPDATE … SET org_id = …` בלי `WHERE` על `drivers` / `vehicles` / `profiles`.  
- תמיד: גיבוי, יצירת טבלת ביניים עם `SELECT`, ואז `UPDATE … WHERE id IN (…)`.
